# Game Observatory

Monitoring games over time — a SQL & Tableau portfolio project.

## M1A — Database foundation

This repository contains a PostgreSQL schema designed for Apple App Store ranking snapshots and Steam player, review, and achievement measurements. No collectors, remote database migrations, or deployments are enabled by this milestone.

See [database setup](docs/DATABASE.md) for instructions after the remaining M1A files are committed. **Do not run remote migrations without explicit approval.**
